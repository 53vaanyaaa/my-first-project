👩‍🏫 QR-коды для групп

Каждая группа сканирует свой код и видит только свою модель (переключателя на другие модели нет). Подпись модели видите только вы: ученикам показывайте QR через «Показать крупно» — там только номер группы. Страницу можно распечатать.
Модели у учеников без подсказок. «🔑 Разгадка» открывает ту же модель с нарисованными золотыми квадратами и спиралью — для обсуждения в конце урока (ученикам эту ссылку не давайте).
