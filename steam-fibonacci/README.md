# STEAM · Фибоначчи и золотое сечение (AR)

Наводишь камеру телефона на лист A4 с маркером — над листом появляется 3D-модель:
🌻 подсолнух (34 и 55 спиралей, золотой угол 137,5°), 🌲 шишка (8 и 13 спиралей), 🐚 наутилус (квадраты 1·1·2·3·5·8·13 и золотая спираль).

## Запуск
1. Распечатай `marker.html` на A4 (без полей, масштаб 100%).
2. Выложи папку на любой HTTPS-хостинг (GitHub Pages, Netlify…) — камера в браузере работает только по HTTPS.
3. Открой `index.html` на телефоне, разреши камеру, наведи на маркер.

`index.html?mode=3d` — режим без камеры (3D-просмотр, для проверки на компьютере).
Локально: `python3 -m http.server` в этой папке и открыть `http://localhost:8000` (на localhost камера тоже работает).

Всё работает офлайн-библиотеками из `lib/` (A-Frame 1.3.0, AR.js 3.4.5). Модели строятся кодом в `app.js`.
